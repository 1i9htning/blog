
## 函数匹配步骤：

### 1. 确定候选函数与可行函数：

先确定候选函数。

**候选函数**：①与被调用函数同名；②其声明在调用点可见

再确定可行函数

**可行函数**：①调用时需要的形参数量与本次调用提供的实参数量相等；②每个实参的类型与对应的形参类型相同，或者能转换成形参的类型

### 2. 寻找最佳匹配：

逐一检查函数调用提供的实参，寻找形参类型与实参类型最匹配的那个可行函数

**如果有且只有一个函数满足下列条件算匹配成功：**

- 该函数的每个实参的匹配都不劣于其他可行函数需要的匹配
- 至少有一个实参的匹配优于其他可行函数提供的匹配

如果检查了所有实参后没有任何一个函数脱颖而出，则该调用时错误的。编译器报错，二义性调用

**最佳匹配规则：越靠前等级越高**

1. **精确匹配，包含三种情况：①实参类型和形参类型相同；②实参从数组类型或函数类型转换成对应的指针类型；③向实参添加顶层const或者从实参中删除顶层const**
2. **通过const转换实现的匹配**
3. **通过类型提升实现的匹配（类型提升见类型转换）**
4. **通过算术类型转换或者指针转换实现的匹配**
5. **通过类类型转换实现的匹配**

## 需要类型提升和算术类型转换的匹配：

**小整型一般会提升到int类型或者更大的整数类型。比如有一个short版本的，另一个是int版本的，则只有当调用提供的是short类型的时候才会选择short版本。即使实参是一个很小的整数值比如char，也会直接将它提升成int类型**

所有算术类型转换的级别都一样。例如，从int向unsigned int转换并不比int向double的转换级别高

```c++
void manip(long);
void manip(float);
manip(3.14);//错误！二义性调用！因为double到long和double到flaot的转换级别是一样的
```
