
## 注意：

- **在while条件中定义变量的话，每次循环都会创建并初始化变量！所以不要再while条件中定义变量**
- **尽量不要在程序中使用goto语句！因为它会使得程序难懂又难以修改！**

## 空语句：

仅由一个分号组成

当一个地方逻辑上（实际操作上）不需要语句，但是C++语法上需要时，可以使用空语句

**空块（{}空的花括号）效果等同于空语句**

## 块：

当一个地方逻辑上（实际操作上）需要多条语句，但C++语法上只需要一条语句时，可以使用块

## 条件语句：

### if语句：

当多个if语句嵌套时，且else数量小于if数量，如何知道某个给定的else适合哪个if匹配呢？这个问题叫做**悬垂else**。**规定else与离他最近的尚未匹配的if匹配，从而消除了程序的二义性**

### switch开关语句：

switch语句首先对括号里的表达式求值，该表达式紧跟在关键字switch后面，**可以是一个初始化的变量声明。**表达式的值转换成整数类型，然后与每个case标签的值比较

如果匹配成功，**程序开始执行匹配到的case后的语句直到switch的结尾或者遇上break语句**

**case标签必须是整型常量表达式！任何两个case标签的值都不能一样！**

**case标签后也可以不加任何语句，多个case标签连续出现（没有任何语句）表示这几个标签执行相同的操作**

```c++
switch (i){
case 1:
case 2:
case 3:
    ++i;break}
```

case标签不一定要换行

**default标签：**如果没有任何一个case能够匹配，则执行default标签

标签不应该单独出现，后面必须紧跟一条语句或者另一个标签。**如果程序以一个空default标签结束，应该加上一条空语句或者空块**

**在switch内部定义的变量必须严格规范作用域。因为在同一作用域内，跳过定义并初始化变量的case标签是不被允许的！**

```c++
case true:
    string str;//隐式初始化
    int i = 0;//显式初始化
    double d;//没有初始化
case false:
    str = "zxm";//错误！不能使用跳过了初始化的变量
    cout << i;//错误！不能使用跳过了初始化的变量
    d = 3.14;//正确！d没有被初始化且在作用域内
```

## 迭代循环语句：

### for循环语句：

**for语句中语句头可以定义多个变量，但是只能有一条声明语句！**

**范围for语句中，运算对象必须是一个序列，比如用花括号括起来的初始值列表、数组、或者vector、string等标准库对象，这些标准库类型的共同特点是拥有能返回迭代器的begin和end成员**

**为什么范围for语句中不能改变序列的大小（使用了指针或者迭代器的循环不能改变序列大小）：在for语句中，预存了end()的值，如果改变了大小，迭代器就失效了**

### do-while循环语句：

**do-while循环在while后面要加分号**

**因为执行循环体后判断条件，因此不允许在条件中定义变量，条件中使用的变量必须定义在循环之外！**

### while循环语句：

**在while条件中定义变量的话，每次循环都会创建并初始化变量！所以不要再while条件中定义变量**

## 跳转语句：

### break语句：

中断离他最近的while、do-while、for或者switch语句，并将控制权移交到这些语句后的第一条语句

### continue语句：

结束最近的循环体的当前迭代并立即开始下一次迭代

只能出现在迭代循环语句中，只有当switch被嵌套在迭代循环语句中时才可以出现在switch语句内，但是continue仍然作用于迭代循环语句

### goto语句：

尽量不要在程序中使用goto语句！因为它会使得程序难懂又难以修改！

**语法形式：goto (label)； lable: 语句**

**goto将控制权移交到带有label标签的语句处，goto语句与标签语句必须在同一函数内**

**goto语句不能将程序控制权从变量的作用域之外转移到作用域之内**

```c++
goto end
//i的作用域从此处开始
int i = 10;
end: i = 20;//错误！goto语句在作用域外，标签语句在作用域内，跨过了变量的定义！
```

向后跳跃到一个已经执行的定义是合法的。也**意味着系统将销毁变量并重新创建定义**

```c++
begin:
    int sz = size();
    if(sz<10)
    {
        goto begin;
    }
```

### return语句：

**终结当前正在执行的函数并将控制权返回到调用函数的地方**

**两种使用形式：**

```c++
return;//无返回值的return语句
return i;
```

无返回值的return语句只能用于返回类型为void的函数中。实际上这类函数在最后会隐式地执行return;

一个返回类型为void的函数也可以使用第二种形式的return语句，但是返回的对象必须是另一个返回void的函数。强行令void函数返回其他类型表达式将产生编译错误！

## 异常处理语句：

在try语句块中定义的变量，在块外部无法访问，**特别是在catch语句内也不能访问！！！！**
**例子：err的what成员函数返回值是C风格字符串（即const char\*），此处返回的是初始化一个具体对象时使用的string对象的副本**

```c++
Sales_item s1, s2;
    while(cin>>s1>>s2)
    {
        try
        {
            if(s1.isbn()!=s2.isbn())
            {
                throw runtime_error("The isbn of s1 is different with counterpart of s2!");
            }
            cout << s1 + s2;
            return 0;
        }
        catch (runtime_error err)
        {
            cout << err.what() << "Try again?Enter Y or N" << endl;
            char c;
            cin >> c;
            if(c=='N')
            {
                break;
            }
        }
    }
```

**如果抛出了异常但是没有找到相匹配的catch语句，则程序转到名为terminate的标准库函数**，该函数行为与系统有关，一般情况下，执行该函数将会导致程序非正常退出

多个try语句块互相嵌套时，抛出异常后现在抛出异常的函数内寻找catch语句，若未匹配到则向上一层函数搜索。以此类推，沿着程序执行路径逐层回退，直到找到可以匹配的catch语句

如果程序没有try语句块（自然也没有catch语句块），发生异常时将自动执行terminate函数并终止当前程序
