
## 注意：

- **函数的调用完成两项工作：**①用实参初始化形参（形参的定义和初始化是隐式的）；②将控制权移交给被调函数。此时主调函数的执行被中断，执行被调函数
- **return语句完成两项工作：**①返回语句中的值（如果有）；②将控制权移交给主调函数
- **函数调用包含的工作：**调用前先保存到寄存器，并在返回时恢复；可能需要拷贝实参；程序转向一个新的位置继续执行
- **形参的定义和初始化过程并没有规定顺序！**
- 定义空的形参列表：隐式（只写一个空括号）；**显式（空括号内加一个void，这是C语言继承下来的机制）**
- **任意两个形参都不能同名！而且函数最外层作用域中的局部变量也不能使用与函数形参一样的名字（等待考证）**
- **形参名是可选的，但是如果不设置形参名则代表不会使用到这个形参（因为没有名字自然也无法使用）。但是！在调用函数时依然要为它提供一个实参！**
- 形参在函数的定义中声明；实参是形参的初始值。
- 函数体必须是块！
- **建议在头文件中声明，在源文件中定义，这样可以确保同一函数的所有声明保持一致。一旦想改变函数的接口，只需要改变一条声明语句即可**
- **建议使用引用传递代替指针形参**
- **尽量使用常量引用传递**
- **在含有return语句的循环之后也应该有一条return语句，否则程序就是错误的！**
- 返回值用于初始化调用点的一个临时量，该临时量就是函数调用的结果
- **不要返回局部对象的引用或者指针！**
- **按照习惯，函数声明应该放在合适的头文件中，且只声明一次**
- **constexpr函数默认为内联函数**
- **编译器如果想展开函数仅仅有函数声明是不够的，还需要函数的定义。所以内联函数可以多次定义！但是所有定义必须完全一致！基于这个原因，内联函数一般定义在头文件内**
- **函数体内可以声明函数！不能定义另一个函数！**
- **返回指向数组的指针类型的时候，return语句中的数组名前必须加上取地址符，否则数组名自动转换为指向首元素的指针，类型不是指向数组的指针！**
- **返回指向函数的指针类型的时候，return语句中的函数名前可以不加上取地址符，因为函数名会自动转换为指向该函数类型的函数指针**

## 参数传递：

分为值传递和引用传递

### 值传递：

形参的改变并不会改变传入形参的变量

指针形参也属于值传递，因为传递进去的是指针值（地址）的拷贝，两个指针是不同的指针，指向同一个对象

### 引用传递

**使用引用传递返回额外信息：**如果想要一个函数想要返回不止一个信息，因为函数返回值只能由一个，所以可以使用引用传递一个实参，在函数体内部将需要返回的信息赋值给这个实参

如果需要传递的参数很大，或者需要改变实参的值，就使用引用传递

普通引用传递必须传递实体非常量对象，且不能绑定字面值。（原因见const常量限定符中<const的引用>部分）

### const形参和实参

**当使用值传递时，因为是使用实参来拷贝初始化形参，所以会忽略掉实参的顶层const**

**忽略掉顶层const可能产生意想不到的结果**

```c++
//下列两个函数可以传入的形参是相同的，无论是不是常量都可以作为实参传入，尽管形式上有不同，但是看作是重复定义
void func(const int i){......}//func可以读取i，但是不能改变i的值
void func(int i){......}//错误！重复定义
```

**尽量使用常量引用传递**

## 形参：

### 数组形参：

**方法一：**

**数组不可拷贝！所以不能以值传递的方式传递数组。但是因为数组会自动转化为指针，所以可以利用这个性质把形参写成下面三种类似数组的形式：**

```c++
void func(const int *);
void func(const int[]);//可以看出来，函数的意图是传递一个数组
void func(const int[10]);//这里的维度只能表示我们期望数组含有多少个元素，实际上不能控制传递进来的数组大小，因为我们实际上传递的是首元素的指针！
```

**因为传递数组时，实际上是传递首元素的指针，所以函数并不知道数组的确切大小，提供了三种方法管理指向数组的指针形参：**

- **使用标记指定数组长度：典型案例就是C风格字符串，因为结尾是一个空字符。所以在函数体内设置为指针指向的不为空字符（即标记）才执行操作**
- **使用标准库规范：传递指针的同时，传递指向该数组的一个尾后指针。在函数体内部设置为当指针不等于尾后指针时才执行操作**
- **传递数组大小形参：显示传递一个表示数组大小的形参。设置为当下标不等于数组大小形参是才执行操作**

**使用案例：**

```c++
int get(int *arry, int index)
{
    return arry[index];
    //等价于return *(arry+index);此处地arry自动转换成指向首元素的指针
}
```

**方法二：**

**使用数组的引用作为形参**

**因为维度也是数组类型的一部分，所以定义数组引用形参时必须包括维度**

**此种方法定义形参的函数，在传递实参时数组的维度必须等于形参的维度！**

**如果是实参是花括号的初始值列表，则初始值数量必须小于或等于形参的维度，而且形参必须是常量引用！因为只有常量引用才可以使用字面值或者初始值列表进行初始化（仅限引用传递）**

**传递多维数组：因为多维数组是数组的数组，所以在必须在最后显示加上内层数组的维度**

```c++

void func(const int (*)[10]);//此处省略了形参名字
void func(const int[][10]);//可以看出来，函数的意图是传递一个数组的数组
void func(const int[10][10]);//第一层维度只能表示我们期望外层数组含有多少个元素，实际上不能控制传递进来的数组的大小，因为我们实际上传递的是首元素的指针！
void func(const int (&)[10][10]);//此处省略了形参名字，第一层维度和第二层维度都必须显示指出！
//如果是实参是花括号的初始值列表，则初始值数量必须小于或等于形参的维度，而且形参必须是常量引用！因为只有常量引用才可以使用字面值或者初始值列表进行初始化

//下面的代码没有理解透彻
//但是在多维数组中，如果内层是const数组，而外层是普通数组，使用第四种方法时可以定义成普通引用（看起来是普通的，实际上还是常量引用，因为constarr类型就是const类型）
using constarr = const int[2];//定义内层数组的别名，内层是常量int数组
void func(constarr(&p)[2])；//函数定义的形参是看起来似乎是普通引用，但实际上等同于const int(&p)[2][2]，实际上还是常量引用

```

**类型全部一致：**

- 可以使用[[k7iyoj|初始值列表initializer_list（标准库类型）]]类型的形参（参考C++ Primer P198，但是我感觉用vector之类的也行啊）
- 使用省略符形参，这种方式一般用于C和C++通用类型。而且，大多数类类型的对象在传递给省略符号形参时都无法正确拷贝。省略符形参只能出现在形参列表的最后一个位置。**且省略符形参对应的实参无须类型检查！**

### 函数类型的形参：

和数组一样，不能定义函数类型的形参，但是形参可以是指向函数的指针。此时形参看起来时函数类型，实际上是当成指针使用

**下面的语句中，第1、2、5、6条语句都是等价的声明，但是形式上1、5条相同，2、6条相同。本质都是一样的，编译器自动将表示的函数类型转换为指针**

```c++
void useBigger(int i,int j, bool p(int i));//第三个形参看起来是函数，实际上是函数指针。它将自动转换为指向函数的指针
void useBigger(int i,int j, bool (*p)(int i));//等价于上面的语句。显示地指出形参是指针
typedef bool func(int i);//func是函数类型bool(int i)的别名
typedef bool (*p)(int i);//p是函数指针类型bool(*)(int i)的别名
```

## 返回类型：

**函数使用return语句返回信息（return语句详情见[[xwduo8|语句]]中<跳转语句>部分）**

### void无返回值函数：

**这类函数在最后会隐式地执行无返回值的return语句**

一个返回类型为void的函数也可以使用第二种形式的return语句，但是**返回的对象必须是另一个返回void的函数。**强行令void函数返回其他类型表达式将产生编译错误！

**返回值的类型必须和返回类型保持一致，或者能隐式转换成返回类型**

**在含有return语句的循环之后也应该有一条return语句，否则程序就是错误的！**

### 值的返回过程

返回一个值得方式和初始化一个变量/形参的方式完全一样：**返回值用于初始化调用点的一个临时量，该临时量就是函数调用的结果**

**返回非引用类型时，返回值将拷贝到调用点**

**返回引用类型时，返回结果不会真正拷贝对象**

**不要返回局部对象的引用或者指针！**因为函数调用结束后，局部对象所占的存储空间也随之被释放掉。因此，函数结束意味着局部变量的引用和指针将指向不再有效的内存区域

```c++
const string & func()
{
    string str;
    if(!str.empty())
    {
        return str;//错误！返回局部对象的引用！
    }
    else
    {
        return "Empty";//错误！返回一个局部临时量，字符串字面值转换成一个局部临时string对象
    }
}
```

**如果返回类型为非常量引用，则返回的是左值，否则是右值**

**可以使用return返回一个使用花括号的初始值列表，用这个列表来初始化函数返回的临时量。如果列表为空，则对临时量执行值初始化**

**返回引用类型时，返回的对象与临时量绑定**

```c++
int i = 9;
int j = 8;
int &func(int r)
{
    return (r%2)? i : j;//如果r是偶数，则返回i，将i与临时量绑定
}
```

## 返回数组的指针：

因为数组不可以拷贝，所以不能返回数组。但是曲线救国，我们可以返回数组的指针或引用（必须在修饰符&或\*和函数名加上括号，以表示返回值是一个指针或者引用。不加的话会先与维度绑定，那样就表示返回值是一个数组）

四种方法可以返回数组指针：

### 直接声明：

```c++
int (*func(int i))[10];
```

可以这样理解上述语句：

func(int i)表示调用func函数要用int形参

\*func(int i)表示可以解引用函数返回的结果（或者是函数的返回值是一个指针）

(\*func(int i))[10]表示函数解引用的结果是一个大小是10的数组（或者是函数的返回值指针指向的是一个数组）

int (\*func(int i))[10]表示的是数组存放的元素是int类型

### 类型别名声明：

```c++
using arrTen = int[10];
arrTen* func(int i);
```

### 使用尾置返回类型：

任何函数的定义都能使用尾置返回，适用于返回类型比较复杂的函数。在本该出现返回类型的地方放置一个auto关键字

```c++
auto func(int i)->int(*)[10];
```

### 使用decltype自动类型：

```c++
int arr[10];
decltype(arr) * func(int i)//decltype对象是数组时不会自动转化为指针，返回的是数组类型，所以需要加上指针修饰符
{
    return &arr;//如果不加取地址符，则数组名自动转换为首元素的指针，类型为int*，与返回类型不符
}
```

### 直接声明：

可以这样理解上述语句：

int (\*f1(int))(int\*,int)表示的是返回的函数的返回类型是int类型

## 默认实参

**一旦某个形参被赋予了默认实参，那么它后面的形参都必须包含默认实参**

**声明中存在默认实参，即使定义中没有显示说明，该形参也是有了默认实参的**

如果想使用默认实参，那么在函数调用的时候省略该实参就好了

**只能省略尾部的实参！所以设计形参列表时要合理设计**

```c++

screen('#');//合法但是与用意相违背！用意是想ht和wd采用默认实参，backgrnd实参为'#'，但是因为只能省略尾部实参，所以'#'赋值给了ht，char类型转换成int类型，wd和backgrnd采用默认实参
```

[[多次声明时，函数第一次声明之后的声明，都只能为之前没有默认实参的形参提供默认实参，而且该形参右侧的所有形参都有默认实参，且不能改变已经存在的默认实参

## 内联函数：inline

调用函数比求等价表达式的值要慢一点

内联函数可以避免函数调用的开销

**编译器如果想展开函数仅仅有函数声明是不够的，还需要函数的定义。所以内联函数可以多次定义！但是所有定义必须完全一致！基于这个原因，内联函数一般定义在头文件内**

**内联机制适用于优化规模较小的、流程直接的、频繁调用的函数。很多编译器不支持内联递归函数**

**定义在类内部的函数是隐式的inline函数**

**constexpr函数默认规定为内联函数**

**内联说明只是向编译器发送内联请求，编译器可以忽略这个请求！**

**编译过程中内联函数的调用形式：**

```c++
inline const string& shorterString(const string&s1,const string&s2)
{
    return (s1.size()<s2.size())?s1:s2;
}
cout << shorterString(s1,s2) << endl;
//在编译过程中展开成类似下面的形式：
cout << ((s1.size()<s2.size())?s1:s2) << endl;
```

## constexpr函数：

指的是能用于常量表达式的函数

**constexpr函数默认规定为内联函数**

**编译器如果想展开函数仅仅有函数声明是不够的，还需要函数的定义。所以constexpr函数可以多次定义！但是所有定义必须完全一致！基于这个原因，constexpr函数一般定义在头文件内**

**定义constexpr函数的规定：**

- 函数的返回类型和形参类型都必须是字面值类型，但返回值不一定是个常量
- 函数体内只能有一条return语句。如果添加了其他语句，则这些语句不能进行任何操作（例如空语句、类型别名等）**（VS2022中，此规则已失效，已经可以添加其他执行操作的语句，且可以声明为void类型，不要return语句！）**
- **函数体内调用的其他函数必须是constexpr函数！**

```c++
//下面的函数无法声明成constexpr函数
//形参类型为string，而string类型不是字面值类型
//返回值为标准库string类的成员函数size，size函数不是constexpr函数
bool isShorter(const string &s1, const string &s2)
{
    return s1.size() < s2.size();
}
```

**返回值不一定是个常量，当实参是常量表达式则返回值是常量表达式，反之不是**

```c++
constexpr int new_sz()
{
    return 42;//返回的是一个常量
}
constexpr int scale(int i)
{
    return i*new_sz();
}
constexpr int foo = new_sz();//foo是一个常量表达式
constexpr int a = scale(2);//scale返回的是字面值2和new_sz函数返回值42的乘积，值为84的字面值。a属于常量
int i = 2;
constexpr int b = scale(i);//scale返回的是变量i和和new_sz函数返回值42的乘积，scale(i)不属于常量表达式。所以b不是常量
int c = scale(i);//正确！
```

constexpr函数是隐式的const，将不能更改数据成员（**VS2022中，此条规定已作废**）
