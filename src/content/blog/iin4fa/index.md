
## 注意：

- 数组的大小不便，在某些特殊的应用上程序的性能较好，但是也相应地损失了灵活性
- **数组中间可以包含空字符\0，但是输出的显示效果\0不占空间，即本应该是{'a','b','\0','c'}，输出后显示效果为abc**
- **编译的时候维度应该是已知的，因此维度必须是一个常量表达式，且必须大于0**

```c++
unsigned i1 = 42;//不是常量表达式
constexpr int i2 = 10;//常量表达式
int arr1[i1];//错误！i1不是常量表达式
int arr2[i2]；//正确！
int arr3[get_size()];//当且仅当get_size是一个constexpr函数时正确
```

- **不能使用auto推断数组的类型**
- **数组不支持拷贝和赋值**
- **数组的下标时size_t类型，是一种机器相关的无符号类型，它被设计得足够大以便能表示内存中的任意对象的大小**
- **使用下标返回的是元素的引用**

## 定义和初始化数组对象：

**没有圆括号初始化的形式！**

**默认情况下，数组的元素被默认初始化。因此，在函数体内部定义的某内置类型数组，默认初始化会使数组含有不确定（未定义）的值**

**维度必须是一个常量表达式，且必须大于0，维度是数组类型的一部分**

**当数组被显式初始化时，可以不显式指明维度，维度等于列表初始化种值的个数**

**如果显示指明维度并且给出了初始化列表，那么列表中值个数不能大于维度，如果个数小于维度，则只会用列表初始化靠前的元素，之后的元素被值初始化。**

**如果一个值也不提供，仅一个花括号，此时必须显式指明维度，元素全部进行值初始化，如果元素类型为类类型，则必须有默认构造函数能够使得值初始化正常进行**

```c++
const unsigned sz = 4;
int arr1[3] = {0,1,2};
int arr2[] = {0,1,2};
int arr1[sz] = {0,1,2};//第四个元素被值初始化为0
```

**字符数组可以用字符串字面值进行初始化，其中字面值结尾处的空字符\0也会被拷贝进去**

**数组不支持拷贝和赋值，所以初始化时不能用另一个数组作为其初始值**

## 指针和数组：

**大多数表达式中，使用数组类型的对象其实是使用一个指向该数组首元素的指针。一个例外是使用decltype推断时，返回类型为数组而非指针！使用sizeof时，也不会转换为指针。（详见类型转换中隐式转换部分）**

**使用数组作为一个auto变量的初始值时，推断类型为指针而非数组！**

```c++
int arr[]{0,1,2,3,4};
auto p(arr);//p是一个int类型指针，等价于auto p(&arr[0])
```

**可以获取数组尾元素后的位置的指针作为尾后指针，但这种做法极其容易出错**

**通过使用标准库函数begin和end可以获取数组首元素的指针和尾后指针**

**数组的指针支持表3.6和表3.7（见[[p9tq2f|迭代器]]）中的所有操作，不同的是两个指针相减返回的类型为叫ptrdiff_t标准库类型，是一种机器相关的带符号类型**

**使用下标时，编译器会自动进行数组名字到指针的转换**

```c++
int arr[]{0,1,2,3};
int i = ia[2];//等价于下面的语句
//int *p = ia;
//int i = *(p+2);
```

**只要指针指向的是数组中的元素，都可以执行下标运算**

```c++
int arr[]{0,1,2,3};
int *p = arr[2];//p指向第三个元素
int j = p[-1];//p指向第二个元素，也就是arr[1]
int k = p[-2];//p指向第一个元素，也就是arr[0]
```
